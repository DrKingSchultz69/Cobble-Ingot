Usage

Cost is real spend for api_key rows. For subscription rows it is what the same calls would cost at API prices.

Remote workers

Another machine running Netheron (a server, second PC, dev box). Its tasks appear on your board and you can start tasks there. Paste the link it prints (with ?token=). Reach it directly, via mm tunnel, or an SSH forward: ssh -L 5142:localhost:4142 host → http://localhost:5142/?token=…

Quality watch

Your own small tasks with a check, run on every available model. Shows which model does best on your code, warns when one gets worse, and feeds the router. Running it uses your quota (one task per model per eval).
